# Автоматизация контроля фармакотерапии

## О проекте
Данный проект разработан в рамках курсовой работы по теме «Проектирование базы данных и разработка клиентского приложения для автоматизации контроля фармакотерапии». Цель проекта — автоматизировать процессы назначения лекарственных препаратов, контроля совместимости и аллергических реакций со стороны врача, а также учёта приёма лекарств и контроля приверженности терапии со стороны пациента.

## Функциональные возможности
### Для роли «Врач»
- Выбор пациента из списка
- Просмотр активных назначений
- Проверка совместимости и аллергии
- Добавление / удаление препарата
- Выгрузка отчёта

### Для роли «Пациент»
- Просмотр расписания на сегодня
- Отметка о приёме («Принял» / «Пропустил»)
- Архив отметок с датой и временем

## Технологический стек
- **СУБД**: PostgreSQL
- **Бэкенд**: Python (Flask)
- **Фронтенд**: HTML, CSS, JavaScript
- **Версионирование**: Git, GitHub
